# mrspace.online

Mr. Space web stüdyosu sitesi ve Rufcut konsept demosu.

## İçerik
- `index.html` : Ana site (Work, Services, Process, Care, Contact)
- `rufcut/index.html` : Rufcut için çalışan konsept demo (mrspace.online/rufcut). Arama motorlarına kapalı.
- `404.html` : Bulunamayan sayfa
- `og.png`, `og-rufcut.png` : Link paylaşınca çıkan önizleme görselleri
- `CNAME`, `robots.txt`, `sitemap.xml` : Domain ve arama ayarları
- `print/Rufcut_Proposal.pdf` : Termal kağıda basılacak teklif dosyası (QR ile demoya gider). Siteden link verilmiyor.

## Yayına alma (GitHub Pages)
1. GitHub'da yeni repo aç (ör. `mrspace`), bu klasördeki her şeyi ana dizine yükle.
2. Settings > Pages > Branch: `main`, klasör: `/ (root)`.
3. Custom domain: `mrspace.online` yaz, "Enforce HTTPS" işaretle.
4. GoDaddy DNS: dört A kaydı (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) ve `www` için CNAME > `kullaniciadi.github.io`.
